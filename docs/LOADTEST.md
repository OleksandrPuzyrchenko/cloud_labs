## Запуск
```bash
BASE_URL=http://<alb-dns> N=50 k6 run loadtest/script.js
```

## Параметри
- `BASE_URL` — адреса ALB (`terraform output application_endpoints`).
- `N` — кількість віртуальних користувачів на сталій фазі (підібрано: 50).
- Фази: 2 хв наростання, 5 хв стале, 2 хв спад.
- Профіль: 1 POST /api/notes + 9 GET (3× список, 3× щойно створена нотатка, 3× старіші нотатки).

> У сервісі немає сутності автор, тому читання даних автора замінено читанням старіших нотаток за id.

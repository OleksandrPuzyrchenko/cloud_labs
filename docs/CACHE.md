# Кешування читання

## Реалізація
- `GET /api/notes` (найнавантаженіше читання: список росте з кожним записом) працює за схемою **cache-aside** (`app/index.js`):
  1. перевірка Redis (ключ `notes:list`); якщо є — повертається з `X-Cache: HIT`;
  2. інакше `SELECT` з PostgreSQL;
  3. результат зберігається в Redis з TTL **30 с** і повертається (`X-Cache: MISS`).
- Якщо Redis недоступний — сервіс читає з бази.
- Redis — AWS ElastiCache (`app/terraform/redis.tf`), доступний лише з security group ECS-задач.
- Перемикач: змінна Terraform `cache_enabled` -> змінна середовища `CACHE_ENABLED`.
- Кеш спільний для всіх екземплярів. Кеш у пам'яті процесу тут не підходить: кожен екземпляр мав би власну копію, тож клієнти, потрапляючи на різні екземпляри, бачили б різні дані, а після масштабування нові екземпляри починали б з порожнім кешем.
